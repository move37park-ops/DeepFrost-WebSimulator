# DeepFrost Web Simulator 🧊🔥

DeepFrost 프로젝트의 핵심 컴포넌트인 **웹 기반 히트펌프 착상/제상 물리 시뮬레이터**입니다. 별도의 백엔드(서버) 없이, 브라우저 단독으로 열역학 방정식과 서리 성장 모델(Frost Growth Model)을 실시간으로 시뮬레이션할 수 있도록 단일 HTML/JS로 구현되었습니다.

## 🚀 주요 기능
- **열역학 기반 물리 모사**: R-290 냉매의 물성 및 Magnus 포화수증기압 공식을 바탕으로, 외기 온/습도에 따른 착상 속도와 과열도(Superheat) 변화를 정밀하게 계산합니다.
- **실시간 데이터 시각화**: HTML5 Canvas를 활용하여 1초 단위로 업데이트되는 센서 데이터 트렌드(Frost Score, 증발기 온도, 압축기 소비전력 등)를 시각적인 그래프로 보여줍니다.
- **인터랙티브 대시보드 조작**: 사용자가 슬라이더로 온도(-20℃ ~ 10℃)와 습도(50% ~ 100%)를 자유롭게 조절하며 가상의 혹한 환경을 테스트할 수 있습니다.
- **시각적 애니메이션 연동**: 계산된 Frost Score에 맞추어 히트펌프 방열판에 서리가 맺히는 영상(`videoplayback.m4v`)이 프레임 단위로 완벽하게 동기화되어 재생됩니다.

## 🛠 실행 방법
이 시뮬레이터는 어떠한 외부 라이브러리나 설치 파일이 필요하지 않습니다.
1. `simulator.html` 파일을 더블클릭하여 최신 웹 브라우저(Chrome, Edge 등)에서 엽니다.
2. 환경 컨트롤(Environment Controls) 패널에서 온도와 습도를 조작합니다.
3. 시뮬레이터가 서리 진행 점수(Frost Score)를 계산하며, 실시간 텔레메트리 대시보드와 하단 그래프가 갱신되는 것을 확인합니다.
4. Frost Score가 임계점(100)에 도달하면 제상(DEFROST) 버튼을 눌러 회복 과정을 테스트해 볼 수 있습니다.

## 📁 파일 구성
- `simulator.html`: 시뮬레이터 UI 및 자바스크립트 기반 물리 엔진 소스코드
- `videoplayback.m4v`: 실외기 서리 성장 배경 시각화용 영상 파일
- `README.md`: 프로젝트 설명서
